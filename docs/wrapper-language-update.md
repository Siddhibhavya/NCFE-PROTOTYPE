Desktop presentation update

The outer popup now uses existing NCFE blue tokens: #0d47a1 for its surrounding surface, #1565c0 for its title and borders, #1976d2 for all three controls, and #e3f2fd for its content. Restart, Back and Feedback share one button style. Frame 224 retains its original cream and yellow feedback appearance inside the application.

The desktop device preview uses a 402 × 874 display ratio corresponding to Apple's iPhone 17 specification (1206 × 2622 pixels), with a Dynamic Island, original Figma status icons and home indicator. The preview scales to the available window height; direct mobile links retain the full-screen application without desktop controls or a portfolio Close X. Device chrome is a CSS representation, rather than an Apple product render. Reference: https://www.apple.com/iphone-17/specs/

Original language cards, order, labels, typography families and two-column layout are restored from Figma node 130:4357. English, Hindi and Odia remain available; the other 21 cards have native disabled states. The availability explanation appears alongside the phone on desktop and remains available within the application on mobile. Hindi and Odia remain draft translations. Original programme/policy names and images are preserved.

Language confirmation restores Figma node 130:7817: “Confirm your language?”, the original explanatory sentence, and Yes/No actions. Yes opens Home; No returns to the selected card. Dialog keyboard dismissal and focus return are preserved.

Visual evidence: screenshots/wrapper-blue-desktop.png, screenshots/language-grid-mobile.png and screenshots/language-confirmation.png. The changes are limited to the presentation frame and language-selection flow. Native screen-reader checks remain pending; automated checks do not establish WCAG compliance.
